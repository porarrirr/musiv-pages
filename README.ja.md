# Musiv Pages

[English](README.md) | 日本語

音楽リンクを、ユーザーが選んだストリーミングサービス向けのリンクへ変換するiOSアプリ「Musiv」の公開サイトです。製品紹介と、App Store向けのサポート文書をGitHub Pagesで配信します。

## 公開ページ

- `index.html` — 製品紹介
- `support.html` — サポート情報
- `privacy.html` — プライバシーポリシー
- `terms.html` — 利用規約

## ローカルプレビュー

```bash
python3 -m http.server 8765
```

起動後、http://localhost:8765/ を開きます。
