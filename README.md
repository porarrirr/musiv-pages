# Musiv Pages

Musiv（音楽リンクを登録サブスク向けに変換する iOS アプリ）の App Store 向け公開ページです。GitHub Pages で配信します。

| ファイル | 内容 |
|----------|------|
| `index.html` | ランディング |
| `support.html` | サポート |
| `privacy.html` | プライバシーポリシー |
| `terms.html` | 利用規約 |
| `style.css` | 共通スタイル |

## ローカル確認

```sh
python3 -m http.server 8765
```

http://localhost:8765/ を開いて確認してください。
