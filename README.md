# Musiv Pages

English | [日本語](README.ja.md)

The public website for Musiv, an iOS app that converts a music link into a link for the streaming service selected by the user. This repository hosts the product landing page and the documents required for App Store support.

## Published pages

- `index.html` — product introduction
- `support.html` — support information
- `privacy.html` — privacy policy
- `terms.html` — terms of use

## Local preview

```bash
python3 -m http.server 8765
```

Then open http://localhost:8765/.
